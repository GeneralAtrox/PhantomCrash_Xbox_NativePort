The original stats were recovered and compared. Similar weapon roles do not
establish whole-game balance equivalence: armour, fire timing and splash
units differ. Compatible curves use source data; unsupported behavior still
uses editable Phantom Crash adapters. All balance choices remain mod data.

Run `convert-slai-assets` to export the asset library, then
`register-slai-assets` to construct native overlays. Music uses
`convert-slai-music`. Commands, executable addresses, calendar analysis,
balance examples, validation and precise limits are recorded in
[SLAI_INTEGRATION.md](SLAI_INTEGRATION.md).

The asset library is imported and selectable. Native playback integration is
still incomplete in the areas listed above and in the integration notes.
